# ALUMICO — Архитектурные алюминиевые системы (Греция / Россия и СНГ)

Премиальный B2B лендинг + 2 доп страницы в едином стиле.

## Структура сайта
- `index.html` — главная лендинг (фасады, ограждения, ветрозащита, парапеты, подборщик, FAQ, форма расчета)
- `projects.html` — каталог систем и проектов (Fusion Line ORBIT/ELXIS/SYNTESIS, F50 Line ACCORD/HORIZON, Open Air Line THEA, Crystal Line A20/F85/SLIM) + карусели выполненных проектов (Всеволожский, Wine House, Суббота, Искра-Парк, Match Point)
- `contacts.html` — контакты и производство (история с 1982, вертикальное производство, QUALICOAT SEASIDE CLASS, ISO 9001/14001, IFT Rosenheim, Instituto Giordano, EKANAL, 60+ стран экспорта) с упором на макро-фото элемента и архитектурный шик

## Навигация и перелинковка
Все страницы связаны между собой:
- Шапка: Продукция (#products) → Проекты и системы (projects.html) → Применение → О компании → Контакты (contacts.html) → FAQ
- Футер: ссылки на все системы и страницы
- CTA на всех страницах ведут на форму расчета (#request / #contactForm)
- Фильтр-бар на projects.html и карусели

## Ассеты
- `image-search/` — премиальные фото фасадов, ограждений, ветрозащиты (скачаны с Unsplash/Pexels поиска)
- `assets/aluminco/` — оригинальные фото с aluminco.ru (Fusion, F50, Open Air, Crystal, выполненные проекты) для оффлайн-архива
